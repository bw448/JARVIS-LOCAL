# Independent implementation boundary

This directory is maintained as an independently authored product based on user-stated requirements and public third-party interfaces.

No recovered Aivy OS source code, HTML, CSS, JavaScript, Python bytecode, executable resources, icons, prompts, activation data, encrypted identity data, memories, or proprietary model artifacts may be copied into this project. The project must not bypass, alter, reproduce, or depend on another product's activation or licensing mechanism.

The current signal-weave interface, SVG mark, voice state machine, local HTTP API, configuration model, and speech adapters were created specifically for JARVIS LOCAL. Recovered artifacts elsewhere in the workspace remain separate and are not build inputs.

Permitted inputs are:

- requirements independently stated by the user;
- interoperability information and behavior needed for authorized migration;
- public documentation and legitimately licensed APIs or packages;
- original assets and code created for this project.

Authorization to inspect another program does not automatically transfer copyright, trademarks, model licenses, voices, training data, or redistribution rights. Future contributors should preserve this directory boundary and document every newly bundled dependency or model.
