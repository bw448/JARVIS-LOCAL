# 调试强制规则

## 关键：不要猜测

- **必须** 先复现问题再尝试修复
- **必须** 用证据验证假设，不靠猜测
- **必须** 每次只改变一个变量进行测试
- **禁止** 不理解根因就应用修复

## 关键：系统化流程

### 调试步骤

1. **复现** - 确认能稳定复现
2. **隔离** - 哪个模块/版本出问题
3. **分析** - 收集日志、堆栈、状态
4. **定位** - 找到根本原因
5. **修复** - 只修复根因
6. **验证** - 确认修复有效

### 常用技巧

- 二分法定位问题范围
- 添加日志追踪执行路径
- 检查边界条件和异常输入
- 对比正常和异常情况
