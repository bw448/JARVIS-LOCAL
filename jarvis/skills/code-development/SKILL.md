# 代码操作强制规则

## 关键：先读后改

- **必须** 修改任何文件前，先读取内容
- **禁止** 凭记忆或猜测修改文件内容
- **禁止** 覆盖整个文件——必须精确编辑

## 最小改动原则

- **必须** 只改明确要求的内容
- **禁止** 给没改动的代码添加注释
- **禁止** 重构没提到的代码
- **禁止** 添加没要求的类型注解
- **禁止** "顺便优化"没要求的代码

# 文件操作规范

## 编辑文件（推荐）
只修改需要改的部分，保持原有代码风格。

## 创建新文件
仅用于创建新文件，禁止用于修改已有文件。

# Git 操作

## 提交规范
- 使用清晰的提交信息
- 每次提交只做一件事
- 提交前检查改动内容
