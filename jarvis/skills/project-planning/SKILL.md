# 项目规划规范

## 任务分解原则

### SMART 原则
- **S**pecific - 具体明确
- **M**easurable - 可衡量
- **A**chievable - 可实现
- **R**elevant - 相关性
- **T**ime-bound - 有时限

### 分解方法
1. 按功能模块分解
2. 按技术层次分解
3. 按时间阶段分解

## 进度管理

### 优先级矩阵
| | 紧急 | 不紧急 |
|---|---|---|
| **重要** | P0 立即做 | P1 计划做 |
| **不重要** | P2 委托做 | P3 不做 |

### 里程碑设定
- 明确交付物
- 设定检查点
- 预留缓冲时间

## 风险管理

### 风险识别
- 技术风险
- 资源风险
- 进度风险
- 依赖风险

### 风险应对
- 规避 - 消除风险源
- 转移 - 转嫁给第三方
- 减轻 - 降低影响
- 接受 - 准备应急方案
