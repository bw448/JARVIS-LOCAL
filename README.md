# JARVIS LOCAL

**本地优先的个人语音助手** - v1.2.0

## 快速开始

### 方式一：下载离线包（推荐）

从 [Releases](../../releases) 下载最新版本，解压直接运行。

### 方式二：从源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/你的用户名/JARVIS-LOCAL.git
cd JARVIS-LOCAL

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python run.py
```

## 功能特性

- 🎤 **语音交互** - 本地语音识别和合成
- 🧠 **DeepSeek Harness** - 插件式智能体架构
- 💬 **对话记忆** - 向量嵌入语义搜索
- 🔍 **网络搜索** - DuckDuckGo、Bing
- 📄 **文档处理** - PDF、DOCX、XLSX

## 配置

运行配置向导：
```bash
python -m jarvis.settings_manager
```
